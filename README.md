# Vision Tech Engineerings

Responsive React + TypeScript landing page built with Vite, Tailwind CSS, custom CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

Industrial photography is loaded from Unsplash URLs in `src/data/websiteData.ts`, so images and web fonts require an internet connection. The newsletter form is a front-end placeholder; connect it to an email marketing service before collecting subscriptions.
